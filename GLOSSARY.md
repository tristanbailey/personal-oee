# Personal OEE

A personal work tracker that scores a working day in 20-minute blocks using Overall Equipment Effectiveness. This glossary holds the terms the persona and the product both rely on.

## Language

**Flow**:
A working pattern in which the planned number of Work points is delivered consistently from day to day and week to week, with few interruptions. Output that is predictable and slowly improving is in flow; output that is spiky compared with the person's good weeks is not. It is not a run of consecutive Work blocks.
_Avoid_: Focus, deep work, streak
